# 🎬 Netflix Clone — Modern Streaming UI

A polished, responsive Netflix-inspired streaming platform built with modern frontend architecture.  
Browse movies by genre, view details instantly, and experience a premium UI experience across devices.

> 🔥 **Designed & Developed by — _Ankit Sharma (@Ankit-Sharma1011)_**

---

## 🚀 What This Project Is

A functional **Netflix UI clone** built as a learning & performance-focused project.  
It demonstrates how to integrate third-party APIs, build reusable components, manage UI state and design a polished OTT-style interface — just like a real streaming platform.

---

## 🧩 Core Features

✔ Netflix-like Home UI with hero banner  
✔ Genre-wise movie rows & infinite scrolling feel  
✔ Hover cards with description & movie rating  
✔ Movie details modal / trailer preview  
✔ Fully responsive — desktop, tablet, mobile  
✔ TMDB API integration for real-time data  
✔ Clean, modern animations & smooth UX

---
